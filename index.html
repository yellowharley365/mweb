چند پاسخ کوتاه

آیا سایت روی موبایل هم درست نمایش داده می‌شود؟

بله؛ چیدمان صفحه برای موبایل، تبلت و نمایشگر دسکتاپ تنظیم شده است.

برای انتشار به هاست پولی نیاز دارم؟

برای یک سایت استاتیک ساده، می‌توانید از GitHub Pages به‌صورت رایگان استفاده کنید.

چطور رنگ‌ها و نوشته‌ها را تغییر بدهم؟

فایل index.html را ویرایش کنید؛ عنوان‌ها و متن‌ها در HTML و رنگ‌های اصلی در متغیرهای ابتدای CSS هستند.

آیا فرم تماس در این نسخه پیام ارسال می‌کند؟

فرم‌های نمایشی به‌تنهایی اطلاعات را به سرور نمی‌فرستند؛ برای دریافت پیام واقعی باید سرویس فرم یا بک‌اند متصل شود.
